新账号第一次登录

FIRST LOGIN
MAA 只能在这台模拟器上登录过的账号之间切换，所以每个账号要先手动登录一次：
  1. 在总览点「打开游戏（用于登录）」，等 Windows 和游戏打开。
  2. 点「远程操作」，在游戏里登录这个账号（第一次打开游戏时还要同意游戏的用户协议、等待资源下载）。
  3. 把登录界面账号列表里显示的登录名（官服如 138****1234，B 服是昵称）填进账号的「登录名」，填其中一段唯一的部分即可，例如手机号后四位。
只有一个账号时登录名可以留空，MAA 就不切换账号。
